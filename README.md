# 상세페이지 메이커

제품 사진·PDF를 올리면 AI가 상세페이지 구조와 카피를 설계하고, 섹션 이미지를 생성해 1080px 고정 폭으로 내보내는 단일 HTML 앱입니다.

## 사용법

1. `index.html`을 Chrome/Edge에서 엽니다. (서버 불필요)
2. 우측 상단 **API 키 설정**에서 키를 등록합니다.
   - Gemini: 자료 분석·섹션 설계 — https://aistudio.google.com/apikey
   - OpenAI: 섹션 이미지 생성 — https://platform.openai.com/api-keys
3. **자료 등록** → **생성 설정** → **편집 & 결과** 순서로 진행합니다.

## 기능

- 이미지/PDF 최대 8개 업로드 (첫 번째 = 대표 이미지, 드래그로 순서 변경)
- 모델 이미지(선택), 추가 정보, 고객 후기(xlsx/csv/tsv) 분석 반영
- 구성 템플릿 6종, 섹션 수, 카피 언어, 비율(2:3 / 1:1 / 3:2), 스타일
- 텍스트편집 모드(편집 가능한 텍스트 레이어) / 통이미지 모드(AI가 카피를 이미지에 직접 디자인)
- 섹션 추가·복제·삭제·순서 변경, 텍스트 드래그 배치, 폰트·색·그림자·배경 박스
- 섹션별 PNG, 통합 이미지, 전체 ZIP(1080px) 다운로드
- IndexedDB 자동 저장 및 기존 작업 불러오기

## 개인정보

API 키는 브라우저 localStorage에만 저장되며, 요청은 브라우저에서 Google·OpenAI API로 직접 전송됩니다. 별도 서버를 거치지 않습니다.
